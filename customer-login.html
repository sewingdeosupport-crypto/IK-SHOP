Orders placed before account login through the existing Google Sheets checkout will not automatically appear here. A secure backend must link those sheet rows to this verified account before they can be shown.

Admin setup required before login can work
  1. Create a Firebase project at https://console.firebase.google.com/ and add a Web App.
  2. Copy the Firebase web configuration into the firebaseConfig object in this file.
  3. In Firebase Authentication → Sign-in method, enable Phone and Email link (passwordless sign-in). Add sewingdeosupport-crypto.github.io to Authorized domains.
  4. For phone OTP, set up reCAPTCHA and check SMS region/billing limits in Firebase. Test with Firebase test numbers first.
  5. Create a Cloud Firestore database. Publish the owner-only rules below; do not make orders publicly readable.
  6. To show real Google Sheets orders in My Orders, update the Apps Script/order backend to securely verify the Firebase ID token and link every order to the authenticated user's UID. Do not expose a public endpoint that returns orders based only on an email or phone number.

Suggested Firestore security rules for orders

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /orders/{orderId} {
      allow read: if request.auth != null
                  && resource.data.customerUid == request.auth.uid;
      allow write: if false;
    }
  }
}

These rules protect reads but also mean a trusted server/Admin SDK must create order documents. Never put a service-account key or private secret in this GitHub Pages site.
